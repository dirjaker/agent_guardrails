# Agent Guardrails 版本记录

## v1.0.0 (2026-05-30)

### 🎉 初始版本

#### 核心功能
- **Input Filter 模块**
  - Prompt 注入检测
  - SQL 注入检测
  - XSS 攻击检测
  - 命令注入检测
  - 敏感词过滤

- **Output Filter 模块**
  - 邮箱脱敏
  - 手机号脱敏
  - 身份证脱敏
  - 银行卡脱敏
  - API Key 脱敏

- **Tool Guard 模块**
  - 工具权限管理
  - 调用频率限制
  - 参数验证
  - 敏感操作审批

- **Audit Logger 模块**
  - 输入输出记录
  - 工具调用记录
  - 安全事件记录
  - 统计分析

- **Guardrails 主模块**
  - 整合所有防护组件
  - 统一接口

#### 示例代码
- `examples/guardrail_demo.py` - 防护演示

#### 文档
- `README.md` - 项目说明
- `TECHNICAL_DOC.md` - 技术文档
